Fold, read, hold

  • Fold your towers

    Five towers, each splitting into two paths at Tier 4.

  • Read the foes

    Swarms, armour, wings, healers and a boss. Each one has a counter.

  • Hold the Heartstone

    Twenty waves. Pause, play at 2x or 3x, or let the next wave start itself.

  • Spend your Buttons

    Every foe you stop pays. Upgrade, sell, and build again where it matters.

Download and install

Go to the downloads

On the releases page, the newest release is at the top (early test builds are marked Pre-release). Open its Assets and download the zip for your computer. The game is free and still early, so expect rough edges. Because it is not signed by Microsoft or Apple yet, your computer warns you the first time you open it; in most cases the steps below get past that.

The download files still carry the game's working name, Papercraft Kingdom Defense.

Windows

  1. Download …-windows-x86_64.zip. If Edge says it isn't commonly downloaded, click …, Keep, then Show more → Keep anyway.
  2. Right-click the zip, choose Extract All, then open the extracted folder.
  3. Double-click papercraft-kingdom-defense.exe. Keep the .pck file next to it: it holds the game.
  4. If Windows protected your PC appears, click More info, then Run anyway. Windows asks again for each new version.

If Windows says Smart App Control blocked an app, there is no way past it for this build: the game needs a signed release first.

macOS

  1. Download …-macos-universal.zip (it runs on Intel and Apple silicon Macs: macOS 10.15 or newer on Intel, macOS 11 or newer on Apple silicon).
  2. Safari usually unpacks the zip for you; if it is still a zip, double-click it. Drag the app into Applications.
  3. Open the app. macOS says it can't check it for malicious software; click Done (or OK).
  4. Open System Settings → Privacy & Security, scroll down to the message about the game, click Open Anyway and confirm with your password. After that it opens normally.

If macOS still refuses, remove the download flag in Terminal, then open the app again: 

xattr -dr com.apple.quarantine /Applications/Papercraft*.app

Linux

  1. Download …-linux-x86_64.zip.
  2. Unpack it into a new folder (Extract Here in most file managers, or unzip <file>.zip -d papercraft).
  3. Start the game from a terminal (the folder is called papercraft here): 
cd papercraft
chmod +x papercraft-kingdom-defense.x86_64
./papercraft-kingdom-defense.x86_64

Keep the .pck file next to the binary. You can also double-click the binary in your file manager once it is executable.
